# Stack
- OS: Arch Linux
- Shell: fish
- Web Server: nginx
- Database: MariaDB (MySQL-compatible)
- Backend: PHP 8.5+
- Frontend: HTML5, CSS3, JavaScript (ES6+), jQuery (only when vanilla JS is insufficient)
- CSS Preprocessor: SCSS compiled via sassc
- JS Minifier: uglify-js
- Version Control: Git

# Boundaries
- Do not access external APIs or services without explicit permission
- Do not modify files outside the project directory
- Do not execute commands that could harm the system or compromise security
- Do not generate code that violates established coding standards
- NEVER modify cdn/css/*.min.css or cdn/js/*.min.js — these are generated by
  external tools and any changes will be overwritten
- CSS minified files are generated from cdn/sass/*.scss via `sassc --style compressed`
- JavaScript minified files are generated from cdn/js/*.js via `uglifyjs`
- New dependencies must be explicitly noted (packages are audited monthly)
- Environment variables belong in .env.example, NEVER commit .env files

# No MVC
- We do not use Model-View-Controller
- PHP is flat procedural / class-based with require/include for dependencies
- Each .php page includes Aurora, outputs HTML directly, and interacts with the
  database via raw SQL or Aurora's SQL handler
- The backend/ directory contains PHP logic (classes, functions, DB helpers)
  that is not web-accessible
- There is no router, no controller classes, no templating engine beyond
  Aurora's header/footer methods

# Directory Structure
```
├── aurora/              ← Aurora PHP Framework (git submodule)
├── backend/             ← Backend PHP logic (not web-accessible)
├── cdn/                 ← Static assets (cdn.domain.com)
│   ├── css/             ← Minified stylesheets (GENERATED — do not edit)
│   ├── fonts/           ← Web fonts
│   ├── images/          ← Images
│   ├── javascript/      ← Minified scripts (GENERATED — do not edit)
│   ├── sass/            ← SCSS source files (edit these)
│   └── video/           ← Videos
├── www/                 ← Public webroot (domain.com)
├── tests/               ← Pest test suites
│   ├── Unit/
│   ├── Feature/
│   └── Integration/
├── app-subdomain/       ← Optional: sub-projects (app.domain.com)
└── *.sql                ← SQL schema/seed files at project root
```

Projects live in `/nginx/git/<project>` and are symlinked into
`/nginx/https/<domain>` on production.

# File Naming Conventions
- PHP (procedural helpers, config files, etc.): snake_case (index.php, config_loader.php)
- PHP (class, interface, or trait): PascalCase (ClassName.php, InterfaceName.php, TraitName.php)
- All other files: snake_case (my_script.js, site_styles.scss)
- Time-stamped files: append `-YYYYMMDDThhmmss` (report-20240722T143000.php)

# Commenting Standards
## RCS-style Header (REQUIRED on every file)
Every source file must begin with an RCS-style identifier. Update the version
and date on every modification.

```
PHP:  <?php # $KYAULabs: file.php,v 1.0.0 YYYY/MM/DD hh:mm:ss -0700 kyau Exp $
SCSS: // $KYAULabs: file.scss,v 1.0.0 YYYY/MM/DD hh:mm:ss -0700 kyau Exp $
JS:   // $KYAULabs: file.js,v 1.0.0 YYYY/MM/DD hh:mm:ss -0700 kyau Exp $
Bash: # $KYAULabs: file.sh,v 1.0.0 YYYY/MM/DD hh:mm:ss -0700 kyau Exp $
```

## PHPDoc (PSR-5)
- All PHP classes, methods, and functions must have PHPDoc docblocks
- Document parameters, return types, and exceptions

## End-of-File
- All files end with a vim modeline:
  `// vim: ft=<filetype> sts=4 sw=4 ts=4 noet :`
- Tab characters for indentation (no spaces: noet), tab stops at 4

## No extra comments
- Do not add explanatory comments to code unless explicitly requested

# Development Environment
- Local server: `php -S localhost:8000` (nginx NOT used locally)
- Local MariaDB instance for database
- No Docker, no setup scripts required beyond cloning the repo

# Production Environment
- OS: Arch Linux
- Server provisioned via https://github.com/kyaulabs/aarch/blob/master/pkg/nginx.pkg
- Web root: `/nginx/https/<domain>/www` (symlinked from `/nginx/git/<project>/`)
- PHP error log: `/nginx/logs/<domain>/php.log`
- nginx error log: `/nginx/logs/<domain>/<domain>-error.log`
- Temp directory: `/tmp`

## Deployment
- Deploy via `git pull` on the production server
- Post-deploy: clear PHP opcache, regenerate minified assets if SCSS/JS sources changed

# Testing
- Framework: Pest PHP (https://pestphp.com/)
- Directory: `tests/` with subdirectories per category (Unit/, Feature/, Integration/, ...)
- File naming: kebab-case (user-authentication-test.php)
- Minimum code coverage: 80% line coverage
- Run tests: `php vendor/bin/pest --coverage`
- CI verifies tests via GitHub Actions (template-workflows repo)

# Linting & Formatting
Linting runs automatically via `.github/hooks/pre-commit` before `gitleaks`.
Each step is gated — it only runs if the relevant tool/files are present.

## PHP
1. Syntax check: `php -l` on staged PHP files
2. Code style: `php-cs-fixer fix . --dry-run --diff`

## CSS/SCSS

## JavaScript
4. ESLint: `npx eslint "cdn/js/**/*.js" --ignore-pattern "*.min.js"` (config: `eslint.config.mjs`)

# Aurora Framework
- Repository: https://github.com/kyaulabs/aurora
- Added as git submodule in `aurora/` directory
- Include entry point: `require_once(__DIR__ . "/../aurora/aurora.inc.php");`
- Main class: `KYAULabs\Aurora`
- Provides: HTML header/footer templating, SRI, resource preloading, SQL handler,
  performance statistics
- Standard page template:

```php
<?php
# $KYAULabs: index.php,v 1.0.0 YYYY/MM/DD hh:mm:ss -0700 kyau Exp $

$rus = getrusage();
require_once(__DIR__ . "/../aurora/aurora.inc.php");

$site = new KYAULabs\Aurora("index.html", "/cdn", true, true);
$site->title = "Page Title";
$site->description = "Page description for search engines.";
$site->dns = ["cdn.domain.com"];
$site->css = [ 'css/site.min.css' => '//cdn.domain.com/css/site.min.css' ];
$site->js = [ 'js/site.min.js' => '//cdn.domain.com/js/site.min.js' ];
$site->preload = [
    '/css/site.min.css' => 'style',
    '/js/site.min.js' => 'script',
];
$site->htmlHeader();
// page content here
$site->htmlFooter();
```

# Assets & Build Pipeline
- SCSS source: `cdn/sass/*.scss`
  Compile: `sassc --style compressed cdn/sass/source.scss cdn/css/output.min.css`
- JavaScript source: `cdn/js/*.js`
  Minify: `uglifyjs cdn/js/source.js -o cdn/js/output.min.js -c -m`
- Assets are built manually — no automatic pipelines or file watchers
- NEVER edit files in `cdn/css/*.min.css` or `cdn/js/*.min.js` directly
