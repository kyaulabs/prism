# Optional Issue Metadata

Use the repository's existing issue types, labels and progress conventions.
Setup may offer labels as an optional selection; selecting them authorizes the
scoped configuration. Inspect current metadata and preserve unrelated labels.

Useful examples include bug, enhancement, documentation, security, blocked and
needs-info. These are suggestions, not a universal taxonomy or exactly-one-value
contract. Do not create labels, issues or project-board state for an ordinary
coding task unless tracking is requested or established project practice.
