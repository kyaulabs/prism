# Prism 2.0 migration

The coordinated 2.0.0 candidate simplifies the exposed resource surface while
retaining native context deployment and both Core extensions. See the shipped
[resource migration guide](../packages/prism-core/docs/migration-2.0.md) for all
old-to-new names, removed commands, counts and explicit-filter migration steps.

Prism 2.0.0 and Pi 1.5.0 are independent versions. Preparing packages or merging
implementation work does not publish them to npm; registry publication remains
manual. Historical release notes and completed plans remain unchanged.
