# Context Management

Use Pi's native compaction, session history and ordinary project documents.
Keep durable decisions, relevant test evidence and next steps when useful; do
not create a mandatory session-transfer artifact or fixed context-percentage gate.

After compaction or restart, verify the worktree and current requirements before
editing. Preserve unrelated work. Failed tools and credential rejections do not
create session lockouts; diagnose the individual failure and continue safely.
