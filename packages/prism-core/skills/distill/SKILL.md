# Distill

Identify the reader, purpose, exact technical terms and protected text. Draft for
accuracy, then make one purposeful edit pass: remove filler, inflated claims,
vague attribution and repetitive structure. Prefer concrete mechanisms, measured
results and useful headings over promotional language or ceremony.

Keep the author's useful voice and the structure that helps readers act. Do not
invent experience, certainty, personality or facts. Accuracy, user requirements,
required formats and established terminology outrank style preferences. Leave
commands, identifiers, quotations and machine-readable syntax intact.

For detailed wording audits, load [patterns](references/patterns.md) relative to
this skill directory. It is optional detail, not a required recurring pass.
Stop when further editing would polish without improving clarity or usefulness.
