---
description: Generate or update domain context from current code while preserving curated knowledge.
argument-hint: "[domain or focus]"
---

Load `docs-writer` to generate or update `CONTEXT.md` for $ARGUMENTS. Inspect
existing context, relevant code, tests and public contracts. Capture actual domain
terms, entities, relationships, invariants and boundaries; preserve curated text
and flag uncertainty. Missing context is a possible output condition, not a
development prerequisite. Update only requested documentation, not implementation.
